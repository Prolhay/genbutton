# Карта поверх игры

Плавающая кнопка поверх Genshin Impact: нажал — открылась интерактивная карта HoYoLAB,
нажал ещё раз — карта закрылась, и ты снова в игре (игра всё это время остаётся запущенной).

## Как получить APK без Android Studio (через GitHub)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (можно приватный).
2. Загрузите в него всё содержимое этой папки (кнопка Add file → Upload files).
   Важно, чтобы папка `.github` тоже загрузилась (если проводник её скрывает — включите показ скрытых файлов).
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
4. Через 3–5 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `map-overlay-apk`.
5. Распакуйте архив, перекиньте `app-debug.apk` на телефон и установите
   (Android попросит разрешить установку из неизвестных источников).

## Как получить APK через Android Studio

Откройте папку проекта в Android Studio → Build → Build APK(s).

## Использование

1. Откройте приложение «Карта поверх игры».
2. Кнопка 1 — выдайте разрешение «Поверх других окон».
3. Кнопка 2 — запускается плавающая кнопка и сама игра.
4. Нажимайте на круглую кнопку: карта ↔ игра. Кнопку можно перетащить.
5. «Назад» внутри карты ходит по страницам, а на первой странице закрывает карту.
6. Выключить кнопку — в приложении или в уведомлении.

## Заметки

- Вход в аккаунт HoYoLAB внутри карты — через e-mail/пароль. Вход через Google во встроенных браузерах обычно блокируется.
- Адрес карты лежит в `OverlayService.kt` (константа `MAP_URL`).
- Игра во время открытой карты не ставится на паузу — открывайте карту в безопасном месте.
